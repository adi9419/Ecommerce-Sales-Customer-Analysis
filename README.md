E-COMMERCE SALES & CUSTOMER ANALYSIS
PROJECT OVERVIEW:
An end-to-end data analytics project focused on analyzing e-commerce sales, profitability, product performance, and customer purchasing behavior using Excel, MySQL, and Power BI.

TOOLS USED:

Excel: Data cleaning and preparation
MySQL: Data storage, SQL queries, and business analysis
Power BI: Interactive dashboards and visualizations

PROJECT OBJECTIVES:

Analyze total sales, profit, and order volume
Identify top-performing product categories and products
Compare sales performance across states and cities
Analyze payment methods and customer purchasing patterns
Evaluate profit margins and discount-related performance

KEY INSIGHTS:

Top Category: Home & Kitchen
Top-Selling Product: Air Fryer
Top State by Sales: Maharashtra
Most Used Payment Mode: UPI

REPOSITORY CONTENTS:

ecommerce_sales_cleaned.csv — cleaned dataset
ecommerce_analysis.sql — SQL analysis queries
ecommerce_sales_analysis.sql — SQL script and database work
Ecommerce_Sales_Customer_Analytics.pbix — Power BI dashboard

SKILLS DEMONSTRATED:
Data Cleaning · SQL Aggregations · Joins and Grouping Concepts · Business Analysis · KPI Reporting · Power BI Visualization
